## 4. Constats principaux

### 4.1 Soumission des labos

- Tous les labos sont seedés en `GITHUB_LINK` (`prisma/seed-hef.ts:224`).
- Tous les labos sont catégorie `CODE` (`prisma/seed-hef.ts:210`), y compris HEF-150
  (produit) et HEF-160 (IA).
- `MissionSubmission.content` est une seule chaîne (`prisma/schema.prisma:516`).
- L'API n'accepte que `TEXT_RESPONSE` ou une URL (`app/api/missions/route.ts:46-57`).
- Le formulaire n'a qu'un champ (`mission-submission-form.tsx:210-241`).
- La review n'a qu'un bloc « Livrable principal » et une checklist générique
  (`review-panel.tsx:108-132`).
- Le parser n'extrait pas `## Réflexion` (`scripts/hef/parse.mjs`).
- `LAB_TESTS` ne couvre que HEF-010 ; le `PythonRunner` marque la progression Academy,
  pas la soumission.

### 4.2 Espace d'apprentissage

- La leçon est un long Markdown, pas les 13 étapes HEF.
- Les 845 questions de quiz éclair ne sont pas importées.
- Les 338 questions de réflexion ne sont pas collectées.
- Les corrections n'ont pas d'explication ni de feedback par option.
- Pas de carnet d'erreurs, pas de révision espacée.
- Le playground Python est une iframe séparée avec `localStorage`.
- Les labos sont mono-lien, sans Lab Bench.
- Le forum, les notes, les quiz, les labos et les soumissions ne partagent pas le même état.
- Aucune page membre pour le mentor ; l'admin est un placeholder.
- Les modèles `AIConversation` / `AIMessage` existent mais ne sont pas utilisés.
- La CSP `frame-src 'self'` bloque les outils externes embarqués.
