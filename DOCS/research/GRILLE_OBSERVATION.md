# Grille d'observation

## Règle de passage vers FRICTIONS.md / APPRENTISSAGES.md
- **Gravité** : 🔴 bloquant (le membre ne peut pas continuer) / 🟠 friction (le membre hésite ou fait une erreur) / 🟡 mineur (le membre réussit mais avec difficulté)
- **Occurrences** : nombre de membres qui rencontrent le même problème
- **Seuil de passage** : 🔴 × 1 occurrence = friction majeure ; 🟠 × 3 occurrences = friction majeure ; 🟡 × 5 occurrences = friction mineure

## Gabarit de note par étape
Pour chaque étape, noter :
- **Temps** : durée en secondes
- **Hésitations** : "le membre a cherché X pendant Y secondes"
- **Erreurs** : "le membre a cliqué sur Z au lieu de W"
- **Citations** : phrases exactes du membre entre guillemets
- **Gravité** : 🔴 / 🟠 / 🟡

## Gabarit APPRENTISSAGES.md
Pour chaque hypothèse testée :
- **Hypothèse** : H1, H2, etc.
- **Résultat** : validée / invalidée / partiellement
- **Preuve** : citations et observations
- **Action** : ce qu'on fait avec le résultat (D-028)
